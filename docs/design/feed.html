Every reference in the folder is an index rather than a list of cards. A fixed column of times on the left, a wide column of content, a margin carrying marks.

The structure comes from alignment first and rules second. The monospace one has no rules at all — the columns hold themselves together, and a gap in the sequence is rendered as a gap, so absence is visible rather than inferred.

The catalogue adds hairlines only where a section turns over, and marks a transition inside a chronological run with a dashed rule whose caption sits in the gap it opens.

The margin is where the state goes, which keeps the text clean and the register countable.
